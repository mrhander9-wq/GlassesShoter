## 📌 О проекте
Это исходный код браузерного 3D-шутера **GlassesShoter**, написанного на HTML, CSS и JavaScript. 

Я выкладываю его в открытый доступ, чтобы:
1. **Найти баги и ошибки.** Я один (с помощью ИИ) не могу отследить всё. Если вы найдете баг — напишите в Issues.
2. **Помочь другим разработчикам.** Если вы хотите сделать свою браузерную игру, но не знаете, с чего начать — используйте этот код как основу.
3. **Показать, что я умею.** Это мое портфолио как разработчика (Vantage Studio).

---

## 🚀 Как запустить
1. Скачайте все файлы (или клонируйте репозиторий).
2. Откройте файл `index.html` в любом браузере (Chrome, Firefox, Yandex).
3. Играйте!
